Lilith Linux Packages

Official APT package repository for Lilith Linux — Ubuntu-based, COSMIC Desktop, open source.

# Add Lilith Linux repository
curl -fsSL https://blancobam.github.io/lilith-packages/public-key.asc \
  | sudo gpg --dearmor -o /usr/share/keyrings/lilith-archive-keyring.gpg

echo "deb [arch=amd64 signed-by=/usr/share/keyrings/lilith-archive-keyring.gpg] \
  https://blancobam.github.io/lilith-packages stable core xtra" \
  | sudo tee /etc/apt/sources.list.d/lilith-linux.list

sudo apt update && sudo apt install offerings tweakers lilim stake ouija-pad

Integrated Ecosystem

Additional Default Software Sources

Lilith Linux comes configured out of the box with multiple default software sources. While these upstream sources are not maintained by the developer of Lilith Linux, they are fully integrated into the Offerings app and pre-configured with the S8n-System for seamless command and package execution.

Pacstall
AUR-inspired package manager for Ubuntu/Debian, providing access to thousands of community-maintained software packages.
pacstall.dev/packages
Ubuntu 26.04
Upstream Resolute core system listings and full desktop manifests. Enabled natively for maximum package compatibility.
arm64.list • arm64.manifest
Soar
High-performance distro-agnostic standalone package manager leveraging the modern SAB package format.
github.com/pkgforge/soarpkgs
AM App Manager
The AppImage package manager and database containing hundreds of portable Linux apps and scripts.
portable-linux-apps.github.io
Flatpak & Flathub
Sandbox-packaged desktop applications and runtimes repository. Enabled by default.
flathub.org/en
System Integrations
Snaps, Homebrew, and Cargo are enabled by default. All associated command structures and software registries are pre-configured out of the box.
Snaps • Homebrew • Cargo
